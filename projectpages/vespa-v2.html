Vespa App

Overview

Vespa is a Customer Relationship Management application for real estate processes, including listing, renting, and selling properties, along with payment and contract management. The goal is to give brokers, property owners, and tenants one portal for the actions connected to their properties.

The challenge

The application serves three different roles: owners, brokers, and tenants. Each role needs its own permissions and workflows, while the product brings together property listings, visit requests, maintenance, payments, messaging, and contract signing.

Designing and building

I worked on the project for seven months, designing the application UI and developing the initial front-end. I created the first design mockup in Adobe XD and built the interface in React while the back-end developer and project manager developed a REST API alongside the front-end work.

What I built

My front-end work included authentication, private routes and role-based views, property listings, a messaging system, transaction history, and contract signing. I connected the necessary interface components to the REST API to support the product workflows. Once the front-end work was completed, the project was handed back to the client before completion so they could finish the remaining work.
